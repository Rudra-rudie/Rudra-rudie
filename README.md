# 💫 About Me

🔬 Currently holding three campus leadership roles:

- **Webmaster** — IEEE Affiliated Student Body (IASB)
- **Sub-Executive** — AI & ML Wing, AUST Cyber Security and AI Club

🚀 Currently building a full-stack **Inventory & Order Management System** for a real client (M/S Tazim Enterprise) — React + Node.js + PostgreSQL.

🤖 Explored and deployed:
- ESG Sustainability Analyzer (SentenceTransformer + PyTorch multi-task network) on Hugging Face Spaces

- PentestGPT with Gemini API backend
